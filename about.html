About

I'm currently learning C and diving into the Linux kernel to understand how systems really work beneath the surface — from how processes are scheduled to how hardware and software actually talk to each other. It's slow, humbling work, but every bug I fix and every concept that finally clicks makes it worth it.

Alongside this, I work as a Device Developer for Project Elixir, a custom Android ROM, where I maintain full device tree support for Garnet — handling everything from build configurations to ensuring the ROM runs smoothly on real hardware. It's given me hands-on experience with the kind of low-level, close-to-the-metal work that first got me interested in systems programming in the first place.

I'm still early in this journey as a BTech CSE student, but I'd rather spend my time understanding how things actually work than just using them at the surface level.
